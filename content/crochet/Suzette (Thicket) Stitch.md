## Stitch metrics
- Name(s): Suzette, Thicket 
- Turning height: 1 ch
- Spacing: 2
As always, definitions in [[Stitch Metric Definitions]].
## Stitch anatomy
> \[sk, (sc, dc)]

(I'm using the definition [here](https://www.craftyarncouncil.com/standards/crochet-abbreviations) where parentheses mean "work these two into the same stitch.") This one is very similar to the [[Lemon Peel Stitch]], except that it has each \[sc, dc\] group go into the same stitch and skips a stitch to keep the same spacing. For this one, the order matters: if you flip the order, the sides will end up zigzagged as each row will end with a space and shift from the one below.
## Thoughts
I stitched two test swatches of suzette and lemon peel and compared them to each other. To my eye, the suzette stitch seems to be very slightly more uniform as the double crochets lean into the spaces instead of being squished slightly. It's an almost imperceptible change, though, so I think it's a matter of preference which to choose.
## Swatch instructions
1) Start by chaining an odd number of stitches ($2n+1$ where $n$ is the number of stitches desired).
2) Turn.
3) Skip 2nd stitch and crochet sc in 3rd stitch.
4) Crochet dc in the same stitch, then skip a stitch.
5) Repeat 3-4 until the end of the row. The row should end in a sc+dc, not a skipped stitch.
6) Ch 1 and turn.
7) Repeat 3-6 until done with swatch.
