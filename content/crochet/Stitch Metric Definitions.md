Stitch metrics are quantitative descriptors of a stitch that should help describe and categorize it with similar stitches. Crochet isn't really something you can be 100% quantitative about so there will be some categorical or straight up vibes-based measurements, but the goal is to have reliable data, so I will do my best to only include measurable or at least reasonable metrics. 

A lot of these are going to be very straightforward observations that simply don't get formally put down as their own datapoint. (Turning height is a good example; most patterns will just ask you to ch x and turn inline rather than pointing out the height of the stitch in a preamble). The metrics are, in no particular order:
## Name(s)

The names I have seen this stitch referenced as.

## Turning height

The number of chains you need to make when turning the stitch. This is mostly equivalent to asking the height of a stitch.

Turning heights often disagree from source to source (for example, hdc is variously noted as a turning height of 1 or 2).

## Spacing

The width of a singular stitch, counted in stitches. This is relevant when it comes to determining the length of your base chain: disregarding the turning chain(s), the base chain needs to be divisible by the spacing. For example, you need an even number of chains for lemon peel, so your spacing is 2.

Let $s$ be spacing, $t$ turning height, and $n$ any number. The valid length $B$ of a base chain for any stitch is thus:
$$
B = ns + t
$$
This is, of course, assuming you start with a chain. For a starting chain + row of single crochet, foundation single crochet, or similar starting methods, $B=ns$. Only once the foundation is done do you then apply the turning height to turn and begin working the stitch.
