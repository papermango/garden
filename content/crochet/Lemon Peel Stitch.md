As I've been getting into crochet, I've learned that there are a vast number of kinds of stitches out there to work up fabric from, and there's not really a standard place documenting all of these. I want to use this garden to start writing down the ones I find. Starting off with the lemon peel stitch, which I used to make a mini scarf out of 50g of yarn I got on sale.
## Stitch metrics
- Name(s): Lemon Peel
- Turning height: 1 ch
- Spacing: 2 st
As I continue to document these, I'll expand on this list of metrics. They'll be defined [[Stitch Metric Definitions|here]]. 
## Stitch anatomy
A lemon peel stitch is alternating single and double crochet: \[sc, dc\]
In my source, every row starts with a single crochet and ends with a double crochet. It likely doesn't matter because you zigzag back and forth as you work up the fabric, but it helps to remember that to avoid skipping stitches by accident.
## Instructions
1) Start by chaining an odd number of stitches ($2n+1$ where $n$ is the number of stitches desired).
2) Turn. (The turning stitch was already made.)
3) Crochet one sc in the 2nd stitch, then one dc in the next, then continue alternating down until the end. You should end in a dc.
4) Ch 1 and turn.
5) Repeat.

## Thoughts
For a complete beginner like me, the lemon peel stitch made a great beginner project to work on my consistency with. Nothing's too complicated and the stitch turned out looking lovely. It seems to be relatively airy as well and drapes solidly (for crochet, at least). It did end up with a flatter texture; I haven't tried flo/blo variations on it yet, which could convert it into an interesting rib-like fabric.
