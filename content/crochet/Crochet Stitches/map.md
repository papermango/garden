The idea here is to collect all the different crochet stitches you can use to build up a fabric and organize them in one place. I'll be adding to this as I find and use more stitches. I'll try to include pictures as much as possible, sometimes a project, sometimes a swatch from spare yarn.

Ultimately this should be a spot to find the desired stitch for a desired fabric type in any project. To that end, I'm going to be as objective as I can - I've defined some [[Stitch Metric Definitions|"metrics"]] to measure off each stitch and will include those measurements in each writeup.
